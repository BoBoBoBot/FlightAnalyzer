## 修复索引模式下捕捉不对应的问题

### 问题
`FindNearestDataRowX` 在索引模式下使用原始索引值 `i`，但图表显示的是 `index * interval`，导致两者不对应。

### 修复
在索引模式下，使用 `index * sampleInterval` 作为X值：
```csharp
xValues = Enumerable.Range(0, yValues.Length).Select(i => (double)i * sampleInterval).ToArray();
```

## 修复鼠标左右键事件互串问题

### 问题
左键有时触发右键事件（框选缩放），右键有时触发左键事件（拖动）。

### 根因
图表外层 Border 上的 ContextMenu 与 ScottPlot WPF 内部的鼠标交互系统冲突：
- WPF 的 ContextMenu 在打开/关闭时会触发 `Mouse.Capture` 变更
- ScottPlot 的 `UserInputProcessor` 接收到的按键状态与实际不一致
- 导致 `LeftClickDragPan` 和 `RightClickDragZoom` 互相误触发

### 修复
1. **移除 Border 上的 ContextMenu**（XAML）
2. **在代码中手动处理右键**（MainWindow.xaml.cs）：
   - `PreviewMouseRightButtonDown`: 记录按下位置
   - `PreviewMouseMove`: 检测是否拖拽（超过最小拖拽距离）
   - `PreviewMouseRightButtonUp`: 若未拖拽则弹出自定义菜单，若已拖拽则让 ScottPlot 处理框选缩放
3. **新增辅助方法**: `XAxisMode_IndexBased_Click_ForPanel` 和 `XAxisMode_ColumnBased_Click_ForPanel`
