## 修复"捕捉数据行"功能

### 问题
`FindNearestDataRowX` 方法没有正确获取X值。当使用"时间"列作为X轴时，它应该使用 `XAxisColumnName` 指定的列作为X值来源，而不是从第一个参数列获取。

### 修复内容

#### MainWindow.xaml.cs
- 修改 `FindNearestDataRowX` 方法签名，添加 `panel` 参数
- 根据 `panel.XAxisMode` 和 `panel.XAxisColumnName` 正确获取X值
- 更新调用处，传递 `panel` 参数

### 测试验证
CSV文件 `test.csv` 的时间范围：
- 第一行：`04:03.5` → `243.5`秒
- 最后一行：`04:09.8` → `249.8`秒

捕捉到249.8是正确的（最后一行的时间值）。

## 修复索引模式下捕捉不对应的问题

### 问题
`FindNearestDataRowX` 在索引模式下使用原始索引值 `i`，但图表显示的是 `index * interval`，导致两者不对应。

### 修复
在索引模式下，使用 `index * sampleInterval` 作为X值：
```csharp
xValues = Enumerable.Range(0, yValues.Length).Select(i => (double)i * sampleInterval).ToArray();
```
