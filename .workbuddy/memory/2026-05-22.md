# 2026-05-22 工作记录

## FlightAnalyzer X轴自定义功能实现

### 需求
用户需要允许将一列元素作为横坐标，同时支持两种显示模式：
1. 按照索引排列（忽略列值，按点索引均匀排列）
2. 按照该列排列（直接使用列值）

需要处理NaN/Null/空值跳过，并解决与跨文件放置数据的冲突。

### 实现内容

#### 1. 数据模型修改 (MainViewModel.cs)
- 新增 `XAxisMode` 枚举：`IndexBased`（默认）和 `ColumnBased`
- `ChartPanel` 类新增属性：
  - `XAxisMode`: X轴模式
  - `XAxisColumnName`: 用作X轴的列名
  - `AvailableXAxisColumns`: 可用X轴列名列表

#### 2. 核心逻辑修改 (MainViewModel.cs)
- `Refresh()` 方法重写：支持两种X轴模式
- `GenerateIndexBasedXData()`: 生成基于索引的X轴数据
- `UpdateAvailableXAxisColumns()`: 从曲线关联文件收集可用列名
- NaN过滤逻辑：跳过X或Y为NaN的点，至少2个有效点才显示
- `HasValidXAxisData()`: 检查X轴列是否有有效数据
- `GenerateTimeTickPositions()`: 生成时间刻度位置
- `GenerateTimeTickLabels()`: 生成时间刻度标签（MM:SS.s格式）
- `CalculateDataBounds()`: 计算所有曲线的最大包围盒

#### 3. CSV导入修复 (CsvFlightImportService.cs)
- 新增 `ParseTimeString()` 方法：解析时间格式字符串 (MM:SS.s) 为秒数
- 支持 "04:03.5" 格式的时间列

#### 4. UI修改 (MainWindow.xaml)
- 图表面板添加右键上下文菜单
- 菜单项：按照索引排列、按照该列排列、选择X轴列

#### 5. 事件处理 (MainWindow.xaml.cs)
- `XAxisMode_IndexBased_Click`: 切换到索引模式
- `XAxisMode_ColumnBased_Click`: 切换到列模式
- `UpdateXAxisColumnMenuItems`: 动态生成列选择菜单
- `XAxisColumnMenuItem_SubmenuOpened`: 菜单打开时更新选项
- 垂直线标签格式：根据X轴模式显示 MM:SS.s 或索引值

### 技术要点
- 跨文件数据对齐：每条曲线使用自己文件的X轴列数据，缺少X轴列时回退到索引模式
- NaN处理：同时检查X和Y值，跳过无效点
- 降采样：超过10000点时自动降采样提升性能
- X轴刻度格式化：使用 NumericManual 显示 MM:SS.s 格式
- 自动缩放：计算所有曲线的最大包围盒并设置轴范围

### 修复的问题
1. CSV时间列格式 "04:03.5" 无法解析为数字的问题
2. 选择X轴列后曲线不显示的问题
3. X轴标签未正确更新的问题
4. X轴刻度格式不直观的问题
5. 自动缩放不准确的问题
